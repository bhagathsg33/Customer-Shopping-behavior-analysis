📊 Customer Shopping Behavior Analysis | Python, SQL & Power BI

📌 Project Overview

This project focuses on analyzing customer shopping behavior to identify purchasing patterns, customer preferences, spending trends, and factors influencing buying decisions.

The objective is to transform raw retail customer data into meaningful business insights using Python, SQL, and Power BI. The project follows an end-to-end data analytics workflow, covering data cleaning, exploratory data analysis, database integration, business querying, data visualization, and insight generation.

The analysis aims to help businesses understand customer behavior, evaluate purchasing trends, and make informed, data-driven decisions.

🎯 Project Objectives

- Analyze customer purchasing patterns and shopping preferences.
- Identify key factors influencing customer purchase decisions.
- Evaluate customer spending behavior and purchase frequency.
- Segment customers based on relevant behavioral characteristics.
- Extract actionable business insights using SQL.
- Develop an interactive Power BI dashboard for business reporting.

🚀 How to Run the Project

Prerequisites

- Python 3.x
- Jupyter Notebook
- MySQL / PostgreSQL / SQL Server
- Power BI Desktop

Step 1: Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd Customer-Behavior-Analysis
```

Step 2: Install Dependencies

```bash
pip install pandas numpy matplotlib seaborn sqlalchemy pymysql
```

Install the appropriate database driver depending on your SQL environment.

Step 3: Execute Python Analysis

Open the Jupyter Notebook:

```bash
jupyter notebook
```

Run `Customer_Shopping_Behavior_Analysis.ipynb` to perform data exploration, cleaning, preprocessing and database integration.

Step 4: Execute SQL Queries

- Create the required database.
- Load the processed dataset.
- Open `customer_behavior_sql_queries.sql`.
- Execute the queries to analyze customer purchasing behavior.

Step 5: Open the Power BI Dashboard

Open `customer_behavior_dashboard.pbix` using Power BI Desktop and connect it to the relevant database if required.
